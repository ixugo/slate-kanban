# 自动更新（internal/web/api/updateapi、web/src/features/update）

## 需求目标

用户打开网页时，服务端去 GitHub release 比较版本，有新版本就弹窗提示；用户可以忽略这个版本，或者立即更新：服务端下载对应平台的包，校验后替换本地程序。

## 决策

| 项 | 决定 |
|---|---|
| 谁会被提示 | 所有构建（含本机编译的）都检查、提示、能自动更新；容器里的程序只提示并引导去下载 |
| 何时提示 | 当前平台的包和 `checksums.txt` 都确认已上传才提示、才允许更新，不按发布时间猜（发布工作流先建 release、后传包，包没传完时 `has_update` 为假）；包一传完，最迟 1 分钟（短缓存）内就能提示；release 一直没有当前平台的包时不会提示 |
| 查询 | 网页每次打开请求 `GET /api/v1/update`；服务端只访问 github.com 网页地址、不用有匿名额度限制的 API：`releases/latest` 的 302 跳转给出 tag，`releases.atom` 给出该 tag 的说明，再对当前平台的包和 `checksums.txt` 的下载地址发 HEAD 确认已上传；成功缓存 1 小时（release 里还没有任何安装包时只缓存 1 分钟，避免发布工作流先建 release、后传包的窗口期被锁住），失败 5 分钟内不重试，失败只记日志、按没有更新返回 |
| 忽略 | 网页把被忽略的版本号写进 localStorage `slate.update.ignored`，小于等于它的版本不再弹窗；不同的电脑仍会提醒 |
| 包的选择 | 按 `GOOS/GOARCH` 找 `slate_<tag>_<系统>_<架构>.tar.gz`（windows 为 `.zip`）和 `checksums.txt`，规则与 Makefile 的 `release/assets` 一致；包地址必须在 `https://github.com/ixugo/slate-kanban/releases/download/` 下 |
| 包内布局 | 程序在包内同名的 `slate_<tag>_<系统>_<架构>/` 目录里，解压后得到单个目录；已发布的旧版平铺包也照样能识别，按名字取最后一段匹配 |
| 校验 | 下载的包必须和 `checksums.txt` 里的 sha256 一致，否则放弃，不改动现有程序 |
| 替换 | 临时文件写在程序所在目录；类 Unix 直接改名覆盖，windows 先把旧程序改名成 `.old` 再放新的，放不上去就改回来；不做备份 |
| 重启 | 替换成功后自动重启：更新接口先返回（`restarting: true`），`app.Run` 收到重启请求后优雅关闭（端口、数据库、日志都释放），再由 `app.Restart` 换成新程序；类 Unix 用 `syscall.Exec` 原地换（PID 不变，launchd/systemd 无感，路径取替换时解析出的真实程序路径，避免 Linux 上 `os.Executable` 带 `(deleted)`），Windows 命令行直接运行时先拉起新进程再退出；Windows 服务模式不自动重启（`restarting: false`），网页提示用户手动重启服务。网页每秒查一次当前版本，变成新版本就自动刷新，等满 60 秒还没起来则改为提示手动重启 |
| 认证 | 接口在 `/api/v1` 下，启用口令时和其他接口一样需要认证 |
| 不能更新时 | 容器里 `can_apply` 为假，弹窗只给「去下载」链接 |

## 风险与已知缺口

| # | 风险 | 处理 |
|---|---|---|
| 1 | 程序所在目录没有写权限 | 下载前就失败，提示没有权限写入，不改动现有程序 |
| 2 | 同时点两次更新 | 同一时刻只允许一次，另一次返回冲突 |
| 3 | 包被篡改或下载不完整 | sha256 校验不过就放弃；包和程序都有大小上限 |
| 4 | GitHub 不通或被限流 | 按没有更新处理，网页不报错 |
| 5 | 工作流和自动更新还没有在真实的 GitHub release 上联调过 | 单元测试用假的 GitHub 覆盖了下载、校验、替换，第一次真实发布后需要实测一次 |

## 验收清单

- [x] 版本比较、缓存、失败不报错、所有构建都查询并可更新、包没传完不提示、包传完立即提示、容器只提示
- [x] 类 Unix 和 windows 的替换，校验不过不改程序且不留临时文件
- [x] 网页：弹窗、忽略、立即更新、失败重试、去下载
- [x] 真实 release 上联调：本机编译的 0.0.1 程序从真实 GitHub 的 v0.1.41 更新，同一 PID 自动重启后版本变为 v0.1.41（macOS）
- [ ] Windows 命令行直接运行时的自动重启未实测（仅交叉编译通过）
