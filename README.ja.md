# Slate

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

Slate は、人と AI エージェントが一緒に使えるローカルファーストのカンバンボードです。ブラウザーでカードを作り、準備ができたタスクを **進行中** に移すと、コーディングエージェントが MCP 経由で引き受けます。作業が終わるとカードが **レビュー** に移り、同じボードで結果を確認できます。

## Docker でインストール

Git、Docker、Docker Compose をインストールしてから、以下のコマンドを実行します。

```sh
git clone https://github.com/ixugo/slate-kanban.git
cd slate-kanban
docker compose up -d --build
```

ブラウザーで [http://127.0.0.1:7070](http://127.0.0.1:7070) を開きます。Compose は取得したソースコードから Slate をビルドし、SQLite データベース、添付ファイル、ログを `slate-data` ボリュームに保存します。更新するには、同じディレクトリのソースコードを更新してから、上の Compose コマンドを再実行します。データを残したまま Slate を停止するには、`docker compose down` を実行します。

単一の実行ファイルを作成する場合や、ローカルで開発する場合は、[ソースからのビルドと開発環境の起動（中国語・簡体字）](docs/development.zh-CN.md)を参照してください。

## 最初のプロジェクトを作る

1. **新しいプロジェクト** を選び、名前を入力して、既定の **開発フロー** テンプレートを使います。**受信トレイ → 未着手 → 進行中 → レビュー → 完了** の列が作成されます。**空白** を選ぶと、**設定 → 列** で列を自由に追加できます。
2. **新しいカード** を選び、作業内容と確認手順を書きます。必要に応じてラベル、優先度、期限、依存関係を追加します。
3. エージェントを接続したら、着手できる状態になったカードを **進行中** にドラッグしてエージェントに任せます。カードが **レビュー** に入ったら、引き継ぎ内容を確認します。問題がなければ **完了** に移し、修正が必要ならコメントを残して **進行中** に戻します。

## AI エージェントを接続する

Slate の **エージェント** ページを開き、1 行のプロンプトを Claude Code、Cursor、Codex のいずれかに貼り付けます。Slate をローカルで実行している場合は、次の文をそのまま送れます。

```text
http://127.0.0.1:7070/install.md を読み、手順に沿って Slate を設定してください。
```

**エージェント** ページから、クライアントに合った MCP 設定とスキルのインストールコマンドをコピーすることもできます。MCP URL の `name` はエージェントごとに変えてください。日常の作業には作業用の設定を使い、列や自動化ルールを編集する場合は管理用の設定を追加します。

MCP と Slate のスキルをインストールしたら、新しいエージェントセッションを開き、`whoami` を呼び出して接続を確認するよう頼みます。続けてプロジェクトの作業を依頼し、エージェントに対応するリポジトリを尋ねられたらローカルパスを確認してください。エージェントはそのリポジトリの Git worktree で作業します。

## ボードを使う

- 画面上部のバーで表示言語を切り替えられます。日本語、英語、中国語の簡体字・繁体字、韓国語に対応しています。
- ボード表示と並べ替え可能なリスト表示を切り替え、検索やフィルターパネルでカードを探せます。たとえば `is:overdue -is:done` で、期限を過ぎた未完了のカードを絞り込めます。
- **設定 → 自動化** でルールを追加できます。開発フローテンプレートはカードが **進行中** と **完了** に入った時刻を記録し、カードが **完了** から出ると完了時刻を消去します。
- **設定 → エクスポート** でプロジェクトを JSON または Markdown としてダウンロードできます。
- localhost または HTTPS で Slate を開くと、ブラウザーのインストール機能から独立したウィンドウで使えます。オフラインでは、最後にキャッシュされたボードのスナップショットを表示できます。

## データとアクセス

- 実行ファイルを直接起動した場合、データの既定の保存先は `~/.slate-kanban/` です。Slate を停止してから `data.db` と `resource/` ディレクトリを一緒にバックアップしてください。Docker を使う場合は、更新時やコンテナの再作成時に `slate-data` ボリュームを保持してください。
- Slate は既定で `0.0.0.0:7070` ですべての IPv4 インターフェースを待ち受け、ローカルネットワークからもアクセスできます。パスコードが未設定の場合、アクセスできる人はすべてのボードを閲覧・編集できます。他の人と共有する場合は、`Server.HTTP.Passcode` を設定し、HTTPS リバースプロキシを使い、公開先のホスト名を `Server.HTTP.AllowedHosts` に追加してください。[ローカル実行の設定例](configs/config.example.toml)と [Docker の設定例](configs/config.docker.toml)を参照してください。
