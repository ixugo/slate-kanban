# Slate

**harness engineering と loop engineering のためのカンバンボード。** ボードを設計するのはあなたです：列、プロンプト、並行数を決めるエンジニア。コーディングエージェントはその上でループを回します：タスクを引き受け、git worktree で作業し、レビューに引き継ぎ、次のタスクを待ちます。

## インストール

1. [最新リリース](https://github.com/ixugo/slate-kanban/releases/latest)を開き、お使いのシステム用のパッケージをダウンロードします：

| システム | パッケージ |
|---|---|
| macOS（Apple シリコン） | `slate_<version>_darwin_arm64.tar.gz` |
| Linux（x86-64） | `slate_<version>_linux_amd64.tar.gz` |
| Linux（ARM64） | `slate_<version>_linux_arm64.tar.gz` |
| Windows（x86-64） | `slate_<version>_windows_amd64.zip` |

2. 新しいフォルダに展開し、そのフォルダで実行します。パッケージにはプログラムと起動・停止スクリプト（`start.sh`、`stop.sh`。Windows は `start.bat`、`stop.bat`）が入っています。Windows ではフォルダに展開して `slate.exe` を実行します。

```sh
mkdir slate && tar -xzf slate_*.tar.gz -C slate
cd slate
./slate
```

3. [http://127.0.0.1:7070](http://127.0.0.1:7070) を開きます。

- macOS で開けないと表示されたら、一度 `xattr -d com.apple.quarantine slate` を実行します。
- Slate をバックグラウンドで動かし、ログイン時に自動起動するには（macOS と Linux）、`./slate -d` を実行します。停止してサービスを削除するには `./slate -stop` を使います。
- 新しいリリースが出ると、ブラウザーに通知が出ます。**今すぐ更新** を選ぶと、Slate が自動で再起動し、ページも自動で再読み込みされます。（Windows サービスとして実行している場合は、サービスを手動で再起動してください。）

## 使い始める

1. **新しいプロジェクト** を選び、**開発フロー** テンプレートのまま使います：**受信トレイ → 未着手 → 進行中 → レビュー → 完了**。受信トレイはあなたの場所で、**未着手** と **進行中** はエージェントが管理します。
2. **エージェント** ページで一言プロンプトをコピーし、Claude Code、Cursor、Codex に渡します。MCP と Slate の skill がインストールされます。
3. 何を作るか、どう確認するかを書いたタスクを追加します。準備ができたら **未着手** に移します。
4. エージェントを動かし続けます：**エージェント** ページの **常時稼働** でプロジェクトを選び、プロンプトをプロジェクトのディレクトリで起動したエージェントのセッションに貼り付けます（`screen` か `tmux` の中で実行すると、ターミナルを閉じても続きます）。エージェントは、更新を待つ、**未着手** から引き受ける、**進行中** に移す、**レビュー** に引き継ぐ、というループを回します。
5. **レビュー** で引き継ぎ内容を確認します。問題なければ **完了** へ、修正が必要ならコメントを残して **進行中** に戻します。

## harness を設計する

- **列のプロンプト**（**設定 → 列**）は、各列でエージェントがしてよいことを伝えます。
- **エンジニア**（**設定 → エンジニア**）は並行枠です：1 人は同時に 1 件のタスクだけを担当します。フルスタック、フロントエンド、バックエンド、UI、テストのエンジニアを採用できます。
- **自動化ルール**（**設定 → 自動化**）は、イベントが起きたときにタスクを移動したりフィールドを設定したりします。

## MCP のトークン計測

分離した SQLite ワークスペース、中国語と英語の固定テストデータ、MCP 2025-06-18、`o200k_base`（tiktoken 0.12.0）を使用しました。テストデータは空のボードとタスクが 4 件あるボードです。そのうち 1 件には 1,770 文字の説明、コメント 5 件、依存関係 2 件があります。比較元は `a8a7a03`、再計測は `e5f8c54` です。

| ツールの検出 | 比較元の既定 | 変更後の既定 | 比較元の管理 | 変更後の旧管理接続 | 変更後の管理ツール公開後 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 表示ツール数 | 19 | 20 | 25 | 22 | 28 |
| サーバーの指示 | 817 | 153 | 241 | 40 | 153 |
| MCP `initialize` の応答 | 931 | 233 | 332 | 117 | 233 |
| MCP `tools/list` の応答 | 5,517 | 4,094 | 7,139 | 5,922 | 6,493 |
| Codex 0.170.0 が Responses に送った Slate 名前空間 | 6,031 | 3,898 | 6,943 | 5,566 | クライアントは既定の 3,898 を保持 |
| Codex が Responses に送った `whoami` の結果オブジェクト | 101 | 94 | 104 | 94 | — |

`enable_management` により既定のツールが 1 つ増えました。旧ツールを 3 つ取り除くと、ビュー全体のツールは重複を除いて 30 から 28 になりました。既定ツール一覧は 25.8%、Codex が送信する Slate 名前空間は 35.4% のトークン減少です。Codex はサーバーの指示を名前空間に 1 回だけ含めます。数値は取得したメッセージを tokenizer で計測した結果です。ログインしたホストでの試行では、プロバイダーの使用量を取得できませんでした。

| 7 回の呼び出しで行うディスパッチの例 | リクエストのトークン | 応答のトークン |
| --- | ---: | ---: |
| 比較元 | 277 | 13,737 |
| 変更後、従来の引数 | 277 | 13,741 |
| 変更後、ボードの読み取りを簡略化 | 285 | 8,044 |

従来の引数を使った場合の小さな差はテストデータのタイムスタンプによるものです。簡略化には `list_boards(summary=true)` と `get_board(include_watch_prompt=false)` を使います。従来の呼び出しでは引き続きボードの全データが返ります。空の待機応答は両バージョンとも 93 トークン、コメントで待機が解除された応答は 261 トークンでした。モデルのターン外でイベントリスナーを待機させることができます。

[再現コマンド、ツールごとの計測値、呼び出しの詳細、ホストの検証](docs/mcp-token-baseline.md#reproduce).

### MCP で Slate を管理する

標準設定で Slate MCP に接続します。ボードの設定、列、自動化を変更したいときは、エージェントに明示的に依頼します。エージェントは `enable_management` で現在の接続に管理ツールを追加します。Codex 0.170.0 は同じスレッドの次のターンでも既定の一覧を使いました。一覧が固定のホストでは `include_tools: true` でカタログを取得し、`tool` に管理ツール名、`arguments` に引数を指定して `enable_management` を再度呼び出せます。分離環境で Codex を使い、この経路で列を実際に作成しました。

従来の作業用接続と旧管理接続は引き続き使用できます。削除された 3 つの MCP ツールに相当する REST 操作は、アクティビティの取得が `GET /api/v1/boards/{id}/events`、タスクの削除が `DELETE /api/v1/cards/{id}`、コメントの削除が `DELETE /api/v1/comments/{id}` です。タスクの計画項目は旧管理接続、Slate のウェブアプリ、REST で設定できます。新規の設定には標準接続 1 つで十分です。

### MCP でタスクを検索する

検索語と絞り込み条件を `list_cards` の `query` に渡します。ウェブ版と同じ構文を使えます。キーワードはタイトル、説明、タスク番号、タグに一致します。例の `board_id` を検索対象のボード番号に置き換えてください。

```json
{"board_id":1,"query":"\"login timeout\" is:open","limit":10}
```

タスクの要約、該当件数 `total`、結果の打ち切りを表す `truncated` が返ります。該当タスクの全文とコメントは `get_card` で取得できます。

検索の説明を更新した結果、既定の 20 ツールの `tools/list` の応答は 4,094 トークンから 4,092 トークンに減りました。[ツール検出の再計測と再現手順](docs/mcp-token-baseline.md#discovery-retest-for-task-search)。

## データとアクセス

- データは `~/.slate-kanban/` にあります。Slate を停止してから `data.db` と `resource/` を一緒にバックアップしてください。
- Slate は `0.0.0.0:7070` で待ち受けます。パスコードが未設定だと、アクセスできる人は全ボードを閲覧・編集できます。共有する前に `Server.HTTP.Passcode` を設定し、HTTPS リバースプロキシの背後に置いてください。[設定例](configs/config.example.toml)を参照してください。
