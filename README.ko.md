# Slate

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

Slate는 사람과 AI 에이전트가 함께 쓰는 로컬 중심의 칸반 보드입니다. 브라우저에서 카드를 만들고 작업 준비가 끝나면 **진행 중** 열로 옮깁니다. 코딩 에이전트가 MCP를 통해 카드를 맡고, 작업을 마치면 **검토** 열로 넘깁니다. 같은 보드에서 결과를 확인할 수 있습니다.

## Docker로 설치

Git, Docker, Docker Compose를 설치한 뒤 다음 명령을 실행합니다.

```sh
git clone https://github.com/ixugo/slate-kanban.git
cd slate-kanban
docker compose up -d --build
```

브라우저에서 [http://127.0.0.1:7070](http://127.0.0.1:7070)을 엽니다. Compose는 내려받은 소스에서 Slate를 빌드하고 SQLite 데이터베이스, 첨부 파일, 로그를 `slate-data` 볼륨에 저장합니다. 업데이트하려면 같은 디렉터리에서 소스를 갱신한 뒤 위 Compose 명령을 다시 실행합니다. 데이터를 보존한 채 Slate를 중지하려면 `docker compose down`을 실행합니다.

단일 실행 파일을 만들거나 로컬 개발 환경을 시작하려면 [소스 빌드 및 개발 환경 실행(중국어 간체)](docs/development.zh-CN.md)을 참고하세요.

## 첫 프로젝트 만들기

1. **새 프로젝트**를 선택하고 이름을 입력한 뒤 기본 **개발 흐름** 템플릿을 사용합니다. **받은 편지함 → 할 일 → 진행 중 → 검토 → 완료** 열이 만들어집니다. **비어 있음**을 선택하면 **설정 → 열**에서 직접 열을 추가할 수 있습니다.
2. **새 카드**를 선택해 작업 내용과 검수 기준을 작성합니다. 필요에 따라 라벨, 우선순위, 마감일 또는 의존성을 추가합니다.
3. 에이전트를 연결한 뒤 준비된 카드를 **진행 중**으로 끌어다 놓아 에이전트에게 맡깁니다. 카드가 **검토**에 들어오면 인수인계 내용을 확인합니다. 검수를 통과하면 **완료**로 옮기고, 수정이 필요하면 댓글을 남긴 뒤 **진행 중**으로 되돌립니다.

## AI 에이전트 연결

Slate의 **에이전트** 페이지를 열고 한 줄 프롬프트를 Claude Code, Cursor 또는 Codex에 붙여 넣습니다. Slate를 로컬에서 실행 중이라면 다음 문장을 그대로 보낼 수 있습니다.

```text
설치 안내 문서(http://127.0.0.1:7070/install.md)를 읽고 안내에 따라 Slate를 설정해 주세요.
```

**에이전트** 페이지에서 클라이언트에 맞는 MCP 설정과 스킬 설치 명령을 복사할 수도 있습니다. MCP URL의 `name`은 에이전트마다 다르게 지정합니다. 일상 작업에는 작업용 설정을 사용하고, 열이나 자동화 규칙을 편집할 때는 관리용 설정을 추가합니다.

MCP와 Slate 스킬을 설치한 뒤 새 에이전트 세션을 열고 `whoami`를 호출해 연결을 확인하도록 요청합니다. 이어서 프로젝트 작업을 맡깁니다. 에이전트가 프로젝트와 연결할 저장소를 물으면 로컬 경로를 확인해 주세요. 에이전트는 해당 저장소의 Git worktree에서 작업합니다.

## 보드 사용하기

- 상단 표시줄에서 화면 언어를 바꿀 수 있습니다. 한국어, 영어, 중국어 간체·번체, 일본어를 지원합니다.
- 보드와 정렬 가능한 목록을 전환하고 검색창이나 필터 패널로 카드를 찾습니다. 예를 들어 `is:overdue -is:done`은 마감일이 지났지만 완료되지 않은 카드를 찾습니다.
- **설정 → 자동화**에서 규칙을 추가합니다. 개발 흐름 템플릿은 카드가 **진행 중**과 **완료**에 들어간 시각을 기록하며, 카드가 **완료**에서 나오면 완료 시각을 지웁니다.
- **설정 → 내보내기**에서 프로젝트를 JSON 또는 Markdown으로 다운로드합니다.
- localhost 또는 HTTPS에서 Slate를 열면 브라우저의 설치 기능으로 독립 창에서 사용할 수 있습니다. 오프라인에서는 마지막으로 캐시된 보드 스냅샷을 볼 수 있습니다.

## 데이터와 접근

- 실행 파일로 실행하면 기본적으로 `~/.slate-kanban/`에 데이터가 저장됩니다. Slate를 중지한 뒤 `data.db`와 `resource/` 디렉터리를 함께 백업합니다. Docker로 실행할 때는 업데이트하거나 컨테이너를 다시 만들 때 `slate-data` 볼륨을 유지합니다.
- 기본적으로 `0.0.0.0:7070`의 모든 IPv4 인터페이스에서 수신하므로 로컬 네트워크에서도 접속할 수 있습니다. 접근 암호가 비어 있으면 접속할 수 있는 사람이 모든 보드를 읽고 편집할 수 있습니다. 다른 사람에게 접근을 열기 전에 `Server.HTTP.Passcode`를 설정하고 HTTPS 리버스 프록시를 사용하며 `Server.HTTP.AllowedHosts`에 외부 호스트 이름을 추가합니다. [로컬 실행 설정 예시](configs/config.example.toml)와 [Docker 설정 예시](configs/config.docker.toml)를 참고하세요.
