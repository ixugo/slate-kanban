# Slate

**harness engineering과 loop engineering을 위한 칸반 보드.** 보드는 당신이 설계합니다: 열, 프롬프트, 동시 작업 수를 정하는 엔지니어. 코딩 에이전트는 그 위에서 루프를 돌립니다: 작업을 맡고, git worktree에서 작업하고, 검토로 넘기고, 다음 작업을 기다립니다.

## 설치

1. [최신 릴리스](https://github.com/ixugo/slate-kanban/releases/latest)를 열고 사용 중인 시스템에 맞는 패키지를 내려받습니다:

| 시스템 | 패키지 |
|---|---|
| macOS (Apple 실리콘) | `slate_<version>_darwin_arm64.tar.gz` |
| Linux (x86-64) | `slate_<version>_linux_amd64.tar.gz` |
| Linux (ARM64) | `slate_<version>_linux_arm64.tar.gz` |
| Windows (x86-64) | `slate_<version>_windows_amd64.zip` |

2. 새 폴더에 압축을 풀고 그 폴더에서 실행합니다. 패키지에는 프로그램과 시작·중지 스크립트(`start.sh`, `stop.sh`. Windows는 `start.bat`, `stop.bat`)가 들어 있습니다. Windows에서는 폴더에 압축을 풀고 `slate.exe`를 실행합니다.

```sh
mkdir slate && tar -xzf slate_*.tar.gz -C slate
cd slate
./slate
```

3. [http://127.0.0.1:7070](http://127.0.0.1:7070)을 엽니다.

- macOS에서 파일을 열 수 없다고 하면 `xattr -d com.apple.quarantine slate`를 한 번 실행합니다.
- Slate를 백그라운드에서 실행하고 로그인할 때 자동으로 시작하려면(macOS와 Linux) `./slate -d`를 실행합니다. 중지하고 서비스를 삭제하려면 `./slate -stop`을 사용합니다.
- 새 릴리스가 나오면 브라우저에 알림이 뜹니다. **지금 업데이트**를 선택하면 Slate가 자동으로 다시 시작되고 페이지도 자동으로 새로고침됩니다. (Windows 서비스로 실행 중이면 서비스를 직접 다시 시작하세요.)

## 시작하기

1. **새 프로젝트**를 선택하고 **개발 흐름** 템플릿을 그대로 사용합니다: **받은 편지함 → 할 일 → 진행 중 → 검토 → 완료**. 받은 편지함은 당신 몫이고, **할 일**과 **진행 중**은 에이전트가 관리합니다.
2. **에이전트** 페이지에서 한 줄 프롬프트를 복사해 Claude Code, Cursor, Codex에 전달합니다. MCP와 Slate skill이 설치됩니다.
3. 무엇을 만들고 어떻게 검증할지 적은 작업을 추가합니다. 준비가 끝나면 **할 일**로 옮깁니다.
4. 에이전트를 계속 실행해 둡니다: **에이전트** 페이지의 **상시 실행**에서 프로젝트를 고르고, 프로젝트 디렉터리에서 시작한 에이전트 세션에 프롬프트를 붙여 넣습니다(`screen`이나 `tmux` 안에서 실행하면 터미널을 닫아도 유지됩니다). 에이전트는 업데이트 대기, **할 일**에서 맡기, **진행 중**으로 옮기기, **검토**로 넘기기를 반복합니다.
5. **검토**에서 인수인계 내용을 확인합니다. 통과하면 **완료**로 옮기고, 수정이 필요하면 댓글을 남기고 **진행 중**으로 되돌립니다.

## harness 설계하기

- **열 프롬프트**(**설정 → 열**)는 각 열에서 에이전트가 해도 되는 일을 알려 줍니다.
- **엔지니어**(**설정 → 엔지니어**)는 동시 작업 슬롯입니다: 한 엔지니어는 한 번에 작업 한 개만 맡습니다. 풀스택, 프런트엔드, 백엔드, UI, 테스트 엔지니어를 채용할 수 있습니다.
- **자동화 규칙**(**설정 → 자동화**)은 이벤트가 생기면 작업을 옮기거나 필드를 설정합니다.

## MCP 토큰 측정

격리된 SQLite 작업 공간, 고정된 중국어·영어 테스트 데이터, MCP 2025-06-18, `o200k_base`(tiktoken 0.12.0)를 사용했습니다. 테스트 데이터는 빈 보드와 작업이 네 개 있는 보드로 구성됩니다. 그중 한 작업에는 1,770자 설명과 댓글 다섯 개, 종속 작업 두 개가 있습니다. 기준 버전은 `a8a7a03`, 재측정 버전은 `e5f8c54`입니다.

| 도구 탐색 | 기준 기본 보기 | 변경 후 기본 보기 | 기준 관리 보기 | 변경 후 기존 관리 연결 | 변경 후 관리 도구 공개 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 표시되는 도구 수 | 19 | 20 | 25 | 22 | 28 |
| 서버 지침 | 817 | 153 | 241 | 40 | 153 |
| MCP `initialize` 응답 | 931 | 233 | 332 | 117 | 233 |
| MCP `tools/list` 응답 | 5,517 | 4,094 | 7,139 | 5,922 | 6,493 |
| Codex 0.170.0이 Responses로 보낸 Slate 네임스페이스 | 6,031 | 3,898 | 6,943 | 5,566 | 클라이언트는 기본값 3,898 유지 |
| Codex가 Responses로 보낸 `whoami` 결과 객체 | 101 | 94 | 104 | 94 | — |

`enable_management`가 기본 도구 목록에 항목 하나를 추가합니다. 기존 도구 세 개를 제거해 전체 보기에서 중복을 제외한 도구 수가 30개에서 28개로 줄었습니다. 기본 도구 목록의 토큰은 25.8%, Codex가 전송하는 Slate 네임스페이스의 토큰은 35.4% 줄었습니다. Codex는 네임스페이스에 서버 지침을 한 번만 포함합니다. 수치는 수집한 메시지에 토크나이저를 적용한 결과입니다. 로그인한 호스트에서 시도했으나 제공업체의 사용량은 얻지 못했습니다.

| 일곱 번 호출하는 작업 배정 예시 | 요청 토큰 | 응답 토큰 |
| --- | ---: | ---: |
| 기준 | 277 | 13,737 |
| 변경 후, 기존 인수 | 277 | 13,741 |
| 변경 후, 간소화된 보드 조회 | 285 | 8,044 |

기존 인수를 사용했을 때의 작은 차이는 테스트 데이터의 타임스탬프에서 발생했습니다. 간소화된 조회는 `list_boards(summary=true)`와 `get_board(include_watch_prompt=false)`를 사용합니다. 기존 호출은 여전히 전체 보드 데이터를 반환합니다. 두 버전 모두 빈 대기 응답은 93토큰, 댓글로 대기가 끝났을 때의 응답은 261토큰이었습니다. 이벤트 리스너는 모델 턴 밖에서 대기할 수 있습니다.

### MCP로 Slate 관리하기

표준 설정으로 Slate MCP에 연결합니다. 보드 설정, 열 또는 자동화를 바꾸려면 에이전트에게 명시적으로 요청하세요. 에이전트는 `enable_management`로 현재 연결에 관리 도구를 공개합니다. Codex 0.170.0은 같은 스레드의 다음 턴에서도 기본 목록을 사용했습니다. 도구 목록이 고정된 호스트는 `include_tools: true`로 카탈로그를 가져온 뒤 `tool`에 관리 도구 이름을, `arguments`에 인수를 넣어 `enable_management`를 다시 호출할 수 있습니다. 격리된 Codex 테스트에서 이 방법으로 실제 열을 만들었습니다.

기존 작업 연결과 레거시 관리 연결도 계속 사용할 수 있습니다. 제거된 MCP 도구 세 개에 대응하는 REST 작업은 활동 조회 `GET /api/v1/boards/{id}/events`, 작업 삭제 `DELETE /api/v1/cards/{id}`, 댓글 삭제 `DELETE /api/v1/comments/{id}`입니다. 작업 계획 필드는 레거시 관리 연결, Slate 웹 앱, REST에서 관리할 수 있습니다. 새 설정에는 표준 연결 하나면 충분합니다.

### MCP로 작업 검색하기

검색어와 필터를 `list_cards`의 `query`에 전달합니다. 웹 검색과 같은 문법을 사용하며 키워드는 제목, 설명, 작업 번호와 태그에 일치합니다. 예시의 `board_id`를 검색할 보드 번호로 바꾸세요.

```json
{"board_id":1,"query":"\"login timeout\" is:open","limit":10}
```

결과에는 작업 요약, 일치한 전체 개수 `total`, 결과가 잘렸는지 나타내는 `truncated`가 포함됩니다. 작업 전체 내용과 댓글은 `get_card`로 읽을 수 있습니다.

검색 설명을 업데이트한 뒤 기본 도구 20개의 `tools/list` 응답은 4,094토큰에서 4,092토큰으로 줄었습니다. [도구 탐색 재측정 및 재현 방법](docs/mcp-token-baseline.md#discovery-retest-for-task-search).

## 데이터와 접근

- 데이터는 `~/.slate-kanban/`에 저장됩니다. Slate를 중지한 뒤 `data.db`와 `resource/`를 함께 백업하세요.
- Slate는 `0.0.0.0:7070`에서 수신합니다. 접근 암호가 비어 있으면 접속할 수 있는 사람이 모든 보드를 읽고 편집할 수 있습니다. 공유하기 전에 `Server.HTTP.Passcode`를 설정하고 HTTPS 리버스 프록시 뒤에 두세요. [설정 예시](configs/config.example.toml)를 참고하세요.
